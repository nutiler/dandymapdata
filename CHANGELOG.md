# DandyMapData 1.2

October 11, 2026. First GitHub texture-pack release; Existing saved settings are retained.

## Enhanced textures

- Optional exported terrain and interior artwork for DandyMap on WoW Forever beta 1.60.1.
- Includes 67 map datasets with terrain zoom levels 0–7, cleaned ocean backgrounds, and outdoor hover textures.
- Includes exported interior placement metadata for supported WMO maps.
- DandyMap detects the enabled pack automatically; the main addon also works without it.

## Download and installation

- Download the installable DandyMapData-1.2.zip from GitHub Releases and extract its DandyMapData folder into Interface/AddOns.
- Includes a file manifest and SHA-256 checksum for the download.

Some included datasets are client test or unused maps. Not every interior floor or transform is supported.
